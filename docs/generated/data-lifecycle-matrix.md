## Static Scan Limits

- Retention policy mapping is inferred from current Java arrays and explicit purge methods.
- `referenced by PurgeEvaluator; verify policy mapping` means the table token appears in purge code, but this generator did not classify it into a specific retention policy branch.
- `not detected` does not automatically mean a bug. Some control/dim tables are intentionally persistent. It does mean the table needs a documented lifecycle decision.
- Runtime database schema verification is not performed by this generator.
