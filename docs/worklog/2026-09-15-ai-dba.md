`api/src/routes/agent-evidence.ts` and their tests. Codex owns investigation,
improvement storage, provider integration, MCP/worker and the conversation UI.

## Verified correction: improvement connection lifetime

The improvement service acquired a second pool connection for its response read
while retaining its transaction connection. A controlled pool double rejected
that acquisition with `SECOND_CONNECTION_REQUESTED_WHILE_FIRST_HELD` before
the correction. This demonstrates the extra acquisition; it is not a production
load measurement.

The service now reads the stored record using the transaction connection before
commit. Repeating the probe passed: one connection, response read before commit,
connection released. `npm run build` in `api` also passed.

## Remaining acceptance evidence

Migration creation and TypeScript builds do not establish a working AI product.
Real PostgreSQL concurrency/idempotency tests, validated gap provenance,
bounded listing/detail responses, provider connection execution, MCP, worker,
conversation/result UI and end-to-end model tests remain outstanding. Existing
provider entries are configuration only, not proof of a tested AI connection.

## Gerçek PostgreSQL ölçümü

`postgres:17-alpine`, tüm V001–V121 migration'ları uygulanmış tek kullanımlık
konteyner. `node --import tsx --test tests/agentEvidence.spec.ts`:
**13 test, 13 geçti, 0 failure, 0 skip**, iki ardışık koşumda aynı.
`tsc --noEmit` exit 0; `ui` build exit 0.

Kapsanan senaryolar: tarihsel pencerenin `now()` ile bayat ilan edilmemesi,
aynı isimli tabloların dbid+relid ile ayrışması, PostgreSQL'in kendi eşik
formülü (reltuples bilinmiyorsa üretilmemesi), çok PID'li tek snapshot'ın tek
toplama turu sayılması, beklenen örnek sayısının uydurulmaması, boş pencerenin
"toplanmıyor" dememesi, desteklenmeyen sürüm ile bilinmeyen capability ayrımı,
NULL'un sıfıra çevrilmemesi, override geçmişinin olmadığının bildirilmesi,
geçersiz girdinin 400 olması, `SET LOCAL statement_timeout`'un havuza
sızmaması, cevapta secret/credential/ham query text bulunmaması.
